# Alfred Workflows

This directory is for storing standalone `.alfredworkflow` files that you want to track separately from the main Alfred sync folder.

## Usage

### Exporting a Workflow

1. Open Alfred Preferences → Workflows
2. Right-click on a workflow
3. Select "Export..."
4. Save to this directory

### Importing Workflows

The bootstrap script will automatically import all `.alfredworkflow` files from this directory.

Or manually: Double-click any `.alfredworkflow` file to import it into Alfred.

## Recommended Workflows

Some popular workflows to consider:
- **Dash** - Quickly search documentation
- **Github** - Search repos, issues, PRs
- **Kill Process** - Quickly kill processes
- **Colors** - Color converter
- **Emoji Search** - Quick emoji picker
- **Stack Overflow** - Search Stack Overflow
- **TimeZones** - World clock converter
- **Calculate Anything** - Advanced calculator

## Note

If you're using Alfred's sync folder (recommended), all workflows are already synced in `Alfred.alfredpreferences/workflows/`. This directory is only for additional standalone workflow files you want to track separately.
